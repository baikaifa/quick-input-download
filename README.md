### ⚠️ 第一次打开会被系统拦一下

安装包**没有买苹果/微软的签名证书**，所以系统对陌生程序会弹警告。这不是病毒，按下面走一遍就行，**不用开终端、不用敲命令**：

- **Windows**：点「更多信息」→「仍要运行」

- **macOS**（首次打开，跟着做一遍，之后永久不再拦）：

  1. 打开 dmg，把 **QuickInput** 拖进左边的「**应用程序**」文件夹
  2. 在「应用程序」里**双击** QuickInput → 会弹「未打开"QuickInput"」
  3. 点「**完成**」（**不要**点「移到废纸篓」）
  4. 打开 **系统设置 → 隐私与安全性**，往下滚到最底部的「**安全性**」一栏
  5. 那一栏里有一行「已阻止"QuickInput"以保护 Mac」→ 点右边的「**仍要打开**」
  6. 再弹一次确认框，还是点「**仍要打开**」

  第 2 步**不要用右键→打开**，macOS 15 之后这个老办法已经失效了，只能走上面第 4 步。

## 常见问题

**跟 Espanso 比怎么样？**

Espanso 免费开源，功能其实**比这个更全**（光标定位、大小写传播、正则触发都支持）。区别在**上手方式**：Espanso 要你写 YAML 配置文件（`espanso edit` 会打开一个黑框框），这个是图形界面，填个表单、把光标位置拖一下就好。**如果你本来就会写配置文件，Espanso 是更划算的选择。**

**跟 Raycast Snippets 比呢？**

Raycast 也免费、有图形界面、全局可用，Windows 版现在也有了。区别是它是个**启动器**，要装一整套东西常驻在系统里；这个只是个单一用途的小工具。

**要联网吗？**

只有激活的时候联网一次。之后日常不联网也能用，凭证 30 天有效、使用过程中自动续期。**云同步默认关闭**，你不主动开就不会上传任何内容。

**换电脑怎么办？**

3 台设备额度，旧机器可以在软件里解绑。

**能退吗？**

¥5 的东西不设退款流程了——**所以请先试用 14 天再付钱**，试用期是完全全功能的，可以先确认它到底合不合你的用法。
