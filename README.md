## 常见问题

**跟 Espanso 比怎么样？**

Espanso 免费开源，功能其实**比这个更全**（光标定位、大小写传播、正则触发都支持）。区别在**上手方式**：Espanso 要你写 YAML 配置文件（`espanso edit` 会打开一个黑框框），这个是图形界面，填个表单、把光标位置拖一下就好。**如果你本来就会写配置文件，Espanso 是更划算的选择。**

**跟 Raycast Snippets 比呢？**

Raycast 也免费、有图形界面、全局可用，Windows 版现在也有了。区别是它是个**启动器**，要装一整套东西常驻在系统里；这个只是个单一用途的小工具。

**要联网吗？**

只有激活的时候联网一次。之后日常不联网也能用，凭证 30 天有效、使用过程中自动续期。**云同步默认关闭**，你不主动开就不会上传任何内容。

**换电脑怎么办？**

3 台设备额度，旧机器可以在软件里解绑。

**能退吗？**

¥5 的东西不设退款流程了——**所以请先试用 14 天再付钱**，试用期是完全全功能的，可以先确认它到底合不合你的用法。
